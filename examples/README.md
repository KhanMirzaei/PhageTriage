# Test data

`Bam35c_NC_005258.1.fasta` is the complete 14,935 bp genome of Bacillus phage
Bam35c, accession `NC_005258.1`. It is included as a reproducible software test
input and is also distributed in PHIST's example data.

Run the easiest end-to-end test with `bash phagetriage.sh demo`, or analyze the
FASTA explicitly as documented in the main README.
